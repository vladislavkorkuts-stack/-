Практическая работа "Создание запросов и отчетов"

  • Откройте эту папку и скопируйте базу данных DB_7.txt. Сохраните базу с именем 11Ф_NN_DB_7.accdb. Это вариант базы "Мосты".

  • Изучите структуру и содержимое таблиц.

  • Сформируйте ленточную форму для таблицы Мосты.

  • Сформируйте следующие запросы:

    1. Мосты, построенные после 1964 года.
    2. Местонахождение мостов, построенных в 1964 году.
    3. Мосты с длиной пролета более 600 метров.
    4. Все сведения о мостах арочного типа.
    5. Мосты определённого года постройки (запрос, который вначале запрашивает интересующий год, а затем выводит сведения о мостах, построенных в этот год).
    6. Мосты определённой страны (запрос, который вначале запрашивает интересующую страну, а затем выводит сведения о мостах, построенных в этой стране).

  • Сформируйте отчеты по каждому запросу.

  • *Добавьте в таблицу поле, в котором возможно размещение фотографии моста.

  • *Добавьте в таблицу несколько фотографий.

  • Сформируйте форму для таблицы "Мосты", в которой отображаюся сведения об одном мосте и его фотография. Поработайте над дизайном этой формы. (Пример для тех, кто не придумал свой дизайн).

  • Создайте отчет "Сведения о мостах с длиной пролета более 600 метров", в котором также выводятся фотографии мостов. ( Пример для тех, кто не придумал свой дизайн).

Задание

Откройте эту папку и скопируйте базу данных DB_8.txt. Сохраните базу с именем 11Ф_NN_DB_8.accdb. Это вариант базы "Экзамены".
Используйте данные этой базы для выполнения задания:

  1. Постройте с помощью MS Excel гистограммы, отображающие результаты экзаменов в каждом классе из исходной базы. Для этого можно:
    • создать нужный запрос (запрос с параметром - названием класса; вычисляемое поле - ученик (см. справку));
    • из него сделать отчет (с группировкой по предметам);
    • экспортировать отчет в MS Excel.
  2. Составьте текстовый документ с отчетом о проделанной работе, в котором будут находиться построенные гистограммы.
    (Результат может быть таким)
  3. Текстовый документ сохраните в папку На проверку/СУБД с именем 11Ф_NN_P1.docx
