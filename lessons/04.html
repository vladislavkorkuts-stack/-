Выполнение арифметических действий над элементами массива

Суммы и произведения, работа с двумя массивами, константы и круговые диаграммы.

Читать в учебнике
01 / РАЗБЕРЁМСЯ

Кратко о главном

НакопительСуммаПроизведение

Для нахождения суммы элементов используют переменную-накопитель. До цикла ей присваивают 0, затем на каждом шаге прибавляют очередной элемент. Для произведения начальное значение равно 1: умножение на ноль уничтожило бы весь результат.

С помощью одного цикла можно обрабатывать два массива одинаковой длины: складывать соответствующие элементы, вычислять сумму произведений или находить различия. При вычислении среднего арифметического сумму делят на число элементов, которое должно быть положительным.

Массив констант удобен для хранения неизменяемых значений, например числа дней в месяцах. Чтобы построить круговую диаграмму для неотрицательных данных с положительной суммой, вычисляют долю каждого значения. Угол сектора равен 360° · a[i] / S.

02 / ПОСМОТРИМ НА ПРИМЕРЕ

Сумма элементов массива

PascalABC.NET 
begin
  var a := Arr(3, 5, 2, 10);
  var s := 0;
  for var i := 0 to a.Length - 1 do
    s := s + a[i];
  Writeln('Сумма = ', s);
end.
Arr создаёт массив с индексацией от нуля. Накопитель принимает значения 0 → 3 → 8 → 10 → 20. Доля первого элемента равна 3/20, угол его сектора — 54°.
03 / ПОПРОБУЙ САМ

Время практики

Выполни задания в тетради или в среде PascalABC.NET, если нужна программа.

  1. Найдите сумму и произведение элементов массива [2, 3, 4].
  2. Вычислите среднее арифметическое чисел [6, 8, 10, 12].
  3. Для значений [10, 20, 30] вычислите углы секторов круговой диаграммы.
Подсказки и ответы

Сумма: 9; произведение: 24. Среднее: 36 / 4 = 9. Углы: 60°, 120°, 180°; их сумма равна 360°.
