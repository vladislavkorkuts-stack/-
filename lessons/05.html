ГЛАВА 1 · § 5 · С. 36–47

Поиск элементов с заданными свойствами

Линейный поиск одного или всех подходящих элементов и подсчёт их количества.

Читать в учебнике
01 / РАЗБЕРЁМСЯ

Кратко о главном

Линейный поискУсловиеСчётчик

Линейный поиск последовательно проверяет элементы массива на соответствие условию. Например, условие a[i] mod 2 = 0 выбирает чётные числа. В худшем случае потребуется проверить каждый элемент массива.

Для поиска первого подходящего элемента можно завершить просмотр сразу после успеха. Нужно отдельно предусмотреть случай, когда ничего не найдено: использовать логический признак или специальное значение индекса, не входящее в допустимый диапазон.

При поиске всех подходящих элементов массив просматривают полностью. Счётчик начинают с нуля и увеличивают при каждом выполнении условия. Не путайте вывод найденных значений и вывод их индексов: это разные результаты.

02 / ПОСМОТРИМ НА ПРИМЕРЕ

Сколько в массиве положительных чисел?

PascalABC.NET 
begin
  var a := Arr(-2, 7, 0, 4, -1);
  var count := 0;
  for var i := 0 to a.Length - 1 do
    if a[i] > 0 then
      count := count + 1;
  Writeln(count);
end.
Условию соответствуют значения 7 и 4. Счётчик равен 2. Ноль не является положительным числом.
03 / ПОПРОБУЙ САМ

Время практики

Выполни задания в тетради или в среде PascalABC.NET, если нужна программа.

  1. В массиве [8, 3, 6, 1, 6] найдите первый элемент, равный 6. Используйте индексы от 1.
  2. Запишите условие поиска чисел, кратных 3 и больших 10.
  3. Измените пример так, чтобы он подсчитывал отрицательные элементы.
Подсказки и ответы

Первый индекс равен 3. Условие: (a[i] mod 3 = 0) and (a[i] > 10). Для отрицательных чисел замените a[i] > 0 на a[i] < 0.
