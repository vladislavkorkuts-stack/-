# Информатика · 10 класс

Статический учебный сайт ГУО «Средняя школа №67 г. Гомеля». Раздел 10 класса переработан по прикреплённому пособию **«Информатика. 10 класс»**, В. М. Котов, А. И. Лапо, Ю. А. Быкадоров, Е. Н. Войтехович, Минск, «Народная асвета», 2020.

## Что входит в курс

- **Введение**: § 1–2, с. 8–21.
- **Глава 1. Алгоритмы обработки массивов**: § 3–7, с. 22–58.
- **Глава 2. Компьютер как универсальное устройство обработки информации**: § 8–15, с. 59–113.
- **Приложение и справочник**: формулы, единицы, степени двойки, схема компьютера, ASCII и UTF-8; ссылки на с. 114–119 пособия.
- В каждой из 15 тем: авторский краткий конспект, пример, три тренировочных задания, подсказки/ответы и вопрос самопроверки.
- Поиск и фильтрация тем, избранное, отметки прохождения, продолжение с первой непройденной темы.
- Страница учебника с просмотром и скачиванием исходного PDF; техника безопасности и существующие документы.

**Это не полная перепечатка учебника.** Подробный материал доступен в оригинальном PDF. Электронные приложения, упоминаемые в книге, не входят в прикреплённый файл и на сайт не добавлялись. Права на пособие принадлежат его правообладателям.

## Запуск

Для просмотра достаточно Python 3:

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Или `npm run dev` (выполняет ту же команду). Открыть `http://localhost:3000` **на своей машине**; в Arena использовать live preview. Браузерный код обращается только по относительным адресам и не содержит обращений к localhost.

Сайт можно разместить на любом статическом хостинге: серверной части, базы данных, внешних шрифтов и CDN нет. Файлы HTML уже сгенерированы и находятся в репозитории. Не следует публиковать `.git`, `node_modules`, `.venv`, тесты и вспомогательные инструменты.

## Структура

| Путь                                                          | Назначение                                                          |
| ------------------------------------------------------------- | ------------------------------------------------------------------- |
| `index.html`, `Программисты.html`                             | Обзор курса 10 класса                                               |
| `!Index/index.html`, `ИОР-Информатика.html`                   | Совместимые точки входа с правильными относительными ссылками       |
| `introduction.html`, `arrays.html`, `computer.html`           | Разделы по оглавлению пособия                                       |
| `lessons/01.html` … `lessons/15.html`                         | Страницы параграфов                                                 |
| `appendix.html`, `textbook.html`, `saved.html`, `safety.html` | Дополнительные разделы                                              |
| `assets/site.css`, `assets/site.js`                           | Общий стиль и интерактивные функции                                 |
| `assets/textbook-10.png`                                      | Обложка, извлечённая из прикреплённого PDF                          |
| `files/informatika-10.pdf`                                    | Прикреплённый учебник, без модификаций                              |
| `scripts/course.json`                                         | Содержание тем и самопроверки                                       |
| `scripts/build.py`                                            | Генератор статических страниц, только стандартная библиотека Python |

Старые страницы и ресурсы 11 класса **не изменены**, включая общие `Pascal.html`, `comp.html` и папку `res/`. Новые разделы 10 класса используют отдельные адреса `arrays.html` и `computer.html`, чтобы не перезаписать материалы, на которые ссылается старый курс. Прежние недостатки старых страниц (например, отсутствующий `nicepage.css`) не относятся к обновлённому курсу и не исправлялись в рамках работы над 10 классом.

## Как менять материалы

1. Отредактировать `scripts/course.json` (конспекты, примеры, задания и вопросы).
2. Для изменения структуры страниц отредактировать `scripts/build.py`.
3. Выполнить `python3 scripts/build.py` или `npm run build`.
4. Выполнить `npm test`.

Сгенерированные HTML включены в репозиторий для обычного статического хостинга. Их нужно обновлять вместе с исходными данными; ручные изменения HTML будут перезаписаны при сборке. PDF содержит обложку, поэтому физическая страница файла на единицу больше напечатанного номера: с. 8 → `#page=9`. Генератор учитывает это автоматически.

## Проверки

Без установки зависимостей:

```bash
npm test
# или
python3 -m unittest discover -s tests
```

Проверяются оглавление и полнота тем, исходные страницы пособия, локальные ссылки и якоря, уникальность ID, структура HTML и локальность ресурсов.

Для браузерных проверок:

```bash
npm ci
npm run dev
# в другом терминале:
npm run test:browser
```

Тесты используют Playwright и Chromium из npm-пакета `@sparticuz/chromium`, поэтому не требуют загрузки браузера с CDN Playwright в ограниченном окружении Arena. Для своего Chromium можно задать `CHROMIUM_PATH`; другой адрес сервера — через `TEST_BASE_URL`.

Браузерные тесты проверяют поиск и фильтры, избранное и его сохранение, прогресс и отмену, все 15 самопроверок, доступность основных типов страниц через axe (WCAG A/AA), 48 комбинаций страниц и ширин 320–1440 px, мобильное меню и фокус, старую точку входа, доступность PDF, работу без localStorage, ошибки JavaScript и неудачные запросы ресурсов. Автоматическая проверка доступности не заменяет ручную.

## Хранение прогресса

Отметки сохраняются только в `localStorage` браузера под ключом `informatics-10-v1`. Персональные данные не запрашиваются, сетевой отправки прогресса нет. Между устройствами прогресс не синхронизируется; при очистке данных браузера он удаляется. Если хранилище недоступно, сайт остаётся работоспособным и предупреждает, что отметки не сохранятся.
